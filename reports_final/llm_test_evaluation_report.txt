4. EVALUATION FRAMEWORK METHODOLOGY
--------------------------------------------------------------------------------
The evaluation engine (src/llm/evaluator.py) inspects 9 dimensions:
  1. Signal Consistency: Matches underlying prediction (BUY/SELL/HOLD).
  2. SHAP Grounding: Checks if top feature attributions appear in rationale text.
  3. Feature Attribution Accuracy: Verifies indicator numerical alignment.
  4. Hallucination Control: Blacklists forbidden ungrounded terms.
  5. Causal Claim Control: Blacklists ungrounded guarantee claims.
  6. Confidence Consistency: Probability tier alignment.
  7. Completeness: Coverage of supporting vs opposing evidence.
  8. Structural Adherence: Markdown / JSON format validation.
  9. Readability: Grammatical correctness and natural flow.
